# RESONANCE · 共振

一款**零素材、纯前端**的音乐游戏：音乐、谱面、音效、背景画面**全部由代码程序化生成**，
打开 `index.html` 就有街机式待机画面、自由演奏（大地图选曲）与制谱工坊，不需要任何外部资源。

> 手感优先：判定、读谱、视角切换与打击反馈都围绕「按得准、看得清」来做。

* **TAP TO START 待机画面** → **手风琴式首页**（点一张卡片展开它、收起其余，默认展开自由演奏）
* **新手教程**：没有存档时，TAP TO START 之后直接进教程——7 步、五种音符**逐个上机**（用真实引擎跑微型谱面），
  「不许 MISS / 不许断连 / 不许踩雷」的通过条件当场判定，失败会给原因并让你重来
* **大地图选曲**：6 个章节区域 / 18 首曲目 / 54 张内置谱面，攒够星级解锁下一片区域；
  每首曲目有三个难度（`EASY` / `HARD` / `EXTREME`）与独立成绩、星级与最佳记录
* **视角写在谱面里**：没有手动 2D/3D 开关，谱面内嵌「切换环节」，副歌/高潮自动切到 3D 并带过场动效；
  **切换后旧视角的轨道与音符会继续画满 3 秒并淡出**，同时游玩界面**不显示当前是 2D 还是 3D**
* **3D 相机完全内置**：FOV 72° / 俯角 48° / 机位 2.1 / **相机距离 2.4** / **速度系数 0.8** / 路面宽 4.2 ——
  设置里**不再有任何 3D 相关项**，判定线在任意参数下都不漂移（离线调参用 `node tests/layout.cjs --pitch 58`）
* **长条只画判定线以上**：`HOLD` / `SLIDE` 的路面以下部分一律不展示（2D 用画布裁剪，3D 把近端夹到 z=0）
* **滑条画成倾斜光束**：从起点轨道斜着连到终点轨道（2D 是平行四边形，3D 是带透视的斜光束），
  还带白色虚线导引与终点落点环——一眼就能看出"要横着走"
* **3D 动效**：音乐呼吸 / 基础倾斜摇摆 / 打击倾斜 / 踩雷强震 + 抖动 / 摇头 / 轨道光柱 / 护栏与隧道环 / 切入俯冲
* 五种音符（游戏里只显示代号）：`TAP` / `HOLD` / `SLIDE` / `FLICK` / `MINE`
  * **FLICK**：外形就是"换了颜色的 `TAP`"（橙色方块）+ **正上方隔着一点小空隙的一个尖顶**。
    触屏/鼠标在判定时刻按下后**朝任意方向滑动**一下即可（**不用松手**）；键盘和 `TAP` 一样按，
    但**必须同时按下两个键**（例如 D 与 K 一起按，或先按住一个再补第二个）。
    只点一下不滑动、或键盘只按一个键 → MISS。
* **判定难度在选曲界面**（与难度选择左右并列，设置里已移除）：`宽松`（判定更宽，**成绩不计入档案**）/
  `标准` / `困难`（判定更窄，**扣血 ×2**）
* **游玩界面极简**：**正上方显示分数与实时精度**、顶部整条血量、右上角暂停键带**一圈进度环**、连击数（3D 时贴在路面上）、
  右下角右对齐的曲名与难度；**底部没有任何文字、没有左下角数据、没有帧率、不显示是几 key、不显示视角**；
  早/晚提示写作 `EARLY` / `LATE`
* **暂停 = `PAUSED`**：不显示任何游戏数据、没有设置入口，只有三个大号符号按钮（▶ ⟲ ✕），按钮与对话框**没有任何背景**
* **结算铺满整页**：统计**分两列逐行列出**（左 6 行 / 右 6 行，`SCORE` / `ACCURACY` / `MAX COMBO` … 尽量用英文），
  两个大号符号按钮（**⟲ 重开 / ⌂ 返回**），**没有「下一首」**
* **设置页 = 整屏预览 + 右侧半透明面板**：预览铺满整屏当背景，选项卡与设置项全部靠右、半透明
* **主页是竖排窄栏**（点一张展开一张，默认展开自由演奏）：按钮竖着排，**不再有清除存档的快捷入口**，
  「玩法说明」已移到**设置 → 游玩**
* **背景艺术全部内置**：11 种场景 + 6 个角色立绘都是 Canvas 路径实时绘制，无外部素材、无网络请求、同 seed 同画面
* 档案：演奏统计、章节进度、成就、存档导出/导入（8 个成就）
* 创作模式：格子制谱器（含视角轨）、自动铺面草稿、吸附量化、撤销重做、导入导出、一键试玩
* **一键清除所有存档**（两步确认，位于设置 → 数据）：成绩、成就、自制谱面、设置一起归零

## 0. 快速开始

无需构建、无需依赖，**双击 `resonance/index.html`** 即可（脚本都是传统 `<script>`，file:// 也能跑）。

```powershell
# 或者用本地服务器（浏览器对 file:// 的音频/存储更严格时）
cd resonance
python -m http.server 8080        # 访问 http://127.0.0.1:8080/
```

进入后先看到的是待机画面：**点一下（或按空格 / Enter）** 进入主页。

* **全新存档**：第一次点击会先进**新手教程**（7 步，两分钟；随时可跳过）。看过教程之后就直接进主页。
* **老存档**：直接进主页，待机画面的按钮会变成「继续 · 第X章」。

主页是**手风琴**：一次只展开一张卡片（点卡片头展开它、收起其他），**默认展开自由演奏**。
`↑`/`↓` 切换卡片，`Enter` 进入展开的卡片，`←` 回到自由演奏，`Esc` 回待机画面。

首次请务必有一次点击/按键——浏览器要求用户手势之后才允许启动音频。

存档存在 `localStorage`（`rg.save.v1` / `rg.settings.v1`），
可在「档案」或「设置 → 数据」里导出为 JSON；「设置 → 数据 → ⛔ 清除所有存档」可以**两步确认后彻底归零**
（成绩、成就、自制谱面、设置全部清除，并重新进入新手教程）。

## 1. 玩法与操作

| 音符 | 外观 | 操作 |
| --- | --- | --- |
| **TAP** | 青色方块 | 判定线上按下对应轨道 |
| **HOLD** | 绿色长条 | 按住不放直到长条结束（提前松手会断连，尾判有容错窗口） |
| **SLIDE** | 黄色长条 + 箭头 | 按住起点轨道，在终点时刻**同时**按住目标轨道 |
| **FLICK** | 橙色方块 + **上方一个小尖顶**（外形与 TAP 完全一致，只是换了颜色） | **触屏/鼠标**：判定时刻按下后**朝任意方向滑动**一下（不用松手）· **键盘**：和单点一样按，但**必须同时按下两个键** |
| **MINE** | 红色旋转尖刺 | **绝对不能按**，踩到扣 12 点血并断连 |

> `FLICK` 的识别完全靠**外形**：没有尖顶的方块就是 `TAP`（按下即可），
> 上方带小尖顶的方块就是 `FLICK`（按下后要**滑动**，或键盘**两键同上**）。2D 画成方块 + 尖顶，
> 3D 是同厚度的方块 + 屏幕空间里贴在它上方的尖顶，编辑器里也一样，教程里还会把 `TAP` 放在旁边做对比。

键盘默认键位（可在设置里为 4/6/8/10 轨分别改键）：`D F J K`（4 键）、`S D F J K L`（6 键）、`A S D F J K L ;`（8 键）。
鼠标与触屏可以直接点击轨道，**支持多点触控**；`SLIDE` 可以按住起点拖动到目标轨道（拖动过程中起点与终点都视为按住）。

判定窗口：宽松 ±52 / 标准 ±40 / 困难 ±28 毫秒（Perfect），并逐级放宽到 Great / Good（难度在选曲界面选）。
精度决定评级：`SS ≥ 99.5%`、`S ≥ 95%`、`A ≥ 90%`、`B ≥ 80%`、`C ≥ 70%`。
星级：通关 ★1、精度 ≥ 90% ★2、精度 ≥ 97% 且未踩雷（或全完美）★3。

`Esc` 暂停 / 继续；暂停画面只有一个 `PAUSED` 和三个大号符号按钮：▶ 继续、⟲ 重开、✕ 退出（不显示数据、也没有设置入口）。

## 2. 视角系统（谱面内嵌 2D ⇄ 3D）
视角不再是一个全局开关，而是**谱面的一部分**：

* `meta.view` 决定起始视角（`2d` / `3d`）；
* `meta.viewEvents` 是一串切换环节 `{t, mode, dur}`：到达 `t` 时用 `dur` 秒过渡到 `mode`；
* 播放时引擎逐帧查询 `RG.Chart.viewAt(chart, 时间)`，到点自动切换，配合**交叉溶解 + 速度线 + 扫描环 + 闪光**过场；
* 切换到 3D 时机位会从远处俯冲进来（`dive`），3D 下的动效包括：
  **音乐呼吸**（低频能量推动镜头起伏）、**基础倾斜摇摆**（按小节周期摆动）、
  **打击倾斜**（命中哪一侧，路面就往那侧下沉）、**踩雷强震动 + 倾斜抖动**、
  **摇头**（roll 联动的小幅 yaw）、**轨道光柱与地面冲量波纹**、
  **两侧护栏 + 小节隧道环**（强化景深）。
* HUD 会显示当前视角，并在切换前 4 秒预告「→ 3D 1.2s」。
* 特效强度设为「关闭」时，上述动效全部停用（只保留静态 3D 画面）。

#### 3D 相机模型（含俯角）
相机就是一个位于判定面后方 `dist`、离地 `height` 的针孔相机，再**绕横轴向下俯 `pitch` 度**：

```
zc = dz·cosθ − (y−H)·sinθ        俯角 θ 之后的相机空间坐标
yc = dz·sinθ + (y−H)·cosθ
屏幕 = (cx + f·x/zc, cy + bob − f·yc/zc)
cy 反解自「判定面必须落在 judgeLine 处」 → 任何 FOV / 俯角 / 机位下判定线都不动
horizonY = cy − f·tanθ           路面消失点（地平线）
```

* 内置参数：FOV **72°**、俯角 **48°**、机位高度 **2.1**、相机距离 **2.4**、**速度系数 0.8**、路面宽度 **4.2**、弯道 0。
  `0°` 完全等价于旧版平视机位（所以老存档的手感不会突然变）。
* `camera.fov`（视野，默认 72°）、`camera.height`（机位高度，默认 2.1）、`camera.dist`（距离，默认 3.6）、`camera.width`（路面宽度，默认 4.2）。
* `node tests/layout.cjs --pitch 58` 可以把任意组合的几何量（地平线、可见纵深带、每轨宽度、顶面纵深）打出来对照。

#### 滑条的倾斜表现
滑条的世界坐标是**两条轨道之间的一条斜光束**，投影后自然呈现倾斜：

* 2D：画成平行四边形（起点轨道 → 终点轨道），叠白色虚线导引 + 终点落点环 + 沿光束方向的方向箭头；
* 3D：光束的近端用**起点轨道**的横向范围、远端用**终点轨道**的横向范围，于是顶面/侧面都是斜的（透视正确）；
* 长按仍然是竖直长条（两端在同一轨道射线上，只有正常的透视收敛）；
* 判定规则没变：按住起点轨道、在终点时刻同时按住终点轨道；鼠标/触屏可以直接从起点拖到终点。

内置谱面由自动铺面算法写入切换环节：**段落强度 ≥2（副歌等）切 3D，其余回 2D**，
高难度谱面还会额外插入一次「切回 2D 再切 3D」的惊喜段落。制谱时可完全自定义。

## 3. 模式：自由演奏 / 创作 / 档案

### 首页：手风琴式卡片
一次只展开一张：点卡片头展开它、其余自动收起（默认展开**自由演奏**）。
主页是**竖排窄栏**（卡片与展开体里的按钮都竖着排），展开体里放的是这一项真正能做的事，而不是一段介绍文字：

| 卡片 | 展开后能给的东西 |
| --- | --- |
| 🗺 自由演奏 | 星级条、通关进度、`▶ 进入大地图` / `随机一首` / `继续上次曲目` |
| 🛠 创作工坊 | 最近的谱面列表、`▶ 进入工坊` / `＋ 新建谱面` / `由乐曲生成草稿` |
| 🗂 档案 | 8 个成就图标（点亮/未解锁）、`▶ 打开档案` / `成就` |
| ⚙ 设置 | **实时预览小画面**、当前判定/皮肤/偏移、`▶ 打开设置` / `玩法说明` |

> 主页**没有清除存档的快捷入口**（那个在设置 → 数据，两步确认）；
> 「玩法说明」也已从主页移走，现在在**设置 → 游玩**（音符表 / 重看新手教程）。

### 新手教程（没有存档时自动进入）
**每次进入都从第一步开始**（不接上次进度）。7 步：`RESONANCE` → `TAP` → `HOLD` → `SLIDE` → `FLICK` → `MINE` → `START`。

**没有文字说明**：每一步都有一段**循环动画演示**，直接演给你看 ——

| 步骤 | 动画演示的内容 |
| --- | --- |
| `TAP` | 方块落到判定线那一瞬，触点按下、涟漪炸开、弹出 `PERFECT` |
| `HOLD` | 长条落下，触点按住不放，长条被"点亮"直到走完才松手 |
| `SLIDE` | 倾斜光束从起点轨道连到终点轨道，触点从起点一路拖到终点，终点亮起 |
| `FLICK` | 旁边放一个 `TAP` 做对比（同形不同色 + 上方尖顶），触点按下后朝右上方划出去，同时**两个键帽一起亮**（键盘两键同上的规则） |
| `MINE` | 手伸过去又缩回来，红色禁止标记 + 警示圈 |
| `RESONANCE` / `START` | 五个代号与它们的音符横排轮播 |

每一步看完演示都要**真的上手弹**：引擎跑一张微型谱面（4 轨、约 9 秒、程序化伴奏），
通过条件就是卡片上方那一行目标（`MISS = 0` / `BREAK = 0` / `MINE = 0`）。
没过不会硬卡住：会给具体原因（"漏了 2 个音符"、"有 1 个长条提前松手"、"踩到 1 个地雷"）并让你原地重来；
教程会话**不进成绩、不会失败退出**，随时可以「跳过教程，直接进主页」。

> 教程界面里不出现音符的中文名：标题、目标、动画里的标注一律只用代号（`TAP / HOLD / SLIDE / FLICK / MINE`）。

### 自由演奏（大地图）
* 拖拽平移、滚轮缩放、双击章节聚焦；左侧章节栏可快速跳转。
* 章节解锁按**总星数**递进：霓虹起点 ★0 → 像素回廊 ★3 → 深海脉冲 ★9 → 熔核矩阵 ★16 → 终焉回声 ★26（隐藏）。
* 章节内曲目需**依次通关**解锁，首领曲有额外光环标记。
* 节点上显示推荐等级、已获星级；右侧面板可选难度、看历史最佳、开始游玩或自动演示。

### 创作模式（制谱工坊）
1. **新建谱面**：从零开始铺面（默认自带一段程序化作曲）。
2. **由乐曲生成草稿**：选一首内置曲目 + 难度等级，引擎跟随鼓点/旋律自动铺面，再手动精修。
3. 编辑器操作：

| 操作 | 说明 |
| --- | --- |
| 左键空白处 | 放置当前类型音符（吸附到网格） |
| 左键拖动音符 | 移动时间与轨道；拖动长条尾部可改时长 |
| 右键音符 | 删除 |
| 空白拖拽 | 框选；`Shift` 点击加选 |
| 右键拖拽 / 滚轮 | 平移时间轴 |
| `Ctrl` + 滚轮 | 缩放时间轴（24~900 px/s） |
| 标尺点击拖动 | 拖动播放头（试听定位） |
| `空格` | 播放 / 暂停；`Q`/`E` 切换吸附加减；`1`~`5` 切换音符类型 |
| `Z`/`X` | 选中音符时间微调 1/16 拍 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（80 步） |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴到光标处 |
| `Ctrl+A` / `Del` / `Esc` | 全选 / 删除选中 / 取消选择 |
| `W` | 选中的长条在 `HOLD` ↔ `SLIDE` 之间切换 |
| 视角轨（左键） | 点空白处按当前时代取反放置切换；拖动改时间；右键删除；`V` 在播放头处切换 |

编辑器左侧多了一条 **视角轨**：竖条颜色表示该段时间的视角（青=2D / 品红=3D），
点击空白处即按当前时代取反放置切换标记，拖动改时间，右键或 `Del` 删除，
工具栏还能设定「起始 2D / 起始 3D」并显示两种视角各占多久。

4. 顶部可改标题、BPM、偏移、轨道数（4/6/8）、时长；右侧有播放控制、节拍器、草稿生成滑块、选中对象属性、快捷键表。
5. **试玩**会直接用编辑器当前内容开一局，退出后回到编辑器；**保存**写入工坊，工坊谱面也会出现在大地图的「创作工坊」节点上。
6. **导出**为标准 JSON 谱面文件，可分享 / 导入。

## 4. 设置项

设置页的布局：**实时预览铺满整屏当背景**（用真正的渲染器 + 一段合成谱面，
`TAP`/`HOLD`/`SLIDE`/`FLICK`/`MINE` 各来一遍循环播放），**选项卡与设置项放在最右侧的一条半透明面板里**。
改任何滑杆、开关、皮肤、判定线、特效强度都会**立刻**反映在整屏预览上，不用进游戏试错、
也不会因为试设置而丢掉一局成绩。

* **游玩**：下落速度、判定偏移（总是「晚」就调大）、默认轨道数、镜像、不失败、自动演示、打击音、显示连击、`EARLY`/`LATE` 提示、**玩法说明入口**（音符表 / 重看新手教程）
* **外观**：音符皮肤（霓虹/极简/实心）、音符大小、背景压暗、特效强度（关闭会同时关掉 3D 动效）、判定线位置（2D 判定线高度，同时决定 3D 判定面落在屏幕的位置）、背景样式（频谱/网格/星空/纯色）
* **音频**：音乐音量、音效音量
* **键位**：4/6/8/10 轨分别改键 + 两套预设，自动去重（预览里会直接显示当前键位）
* **数据**：统计、导出/导入存档、重置进度、重置成就、清空自制谱面、**⛔ 清除所有存档**（两步确认）

> 视角没有开关：2D/3D 由**谱面**决定（见第 2 节）；**3D 相机参数全部内置**，设置里没有任何 3D 项；
> **判定难度**已移到选曲界面（见下）。

### 判定难度（在选曲界面）

打开任意曲目时，面板是**左右两列**：左边是谱面难度（`EASY` 等三档），右边是**判定难度**：

| 档位 | 窗口 | 效果 |
| --- | --- | --- |
| 宽松 | ±52ms | 判定最宽，但**成绩不计入档案**（结算显示 `UNRANKED`，不写入星级与最佳） |
| 标准 | ±40ms | 正常计分 |
| 困难 | ±28ms | 判定最窄，且**扣血 ×2** |

原来的「自定义窗口」档已移除。

## 4.5 背景艺术：全部内置，无网络请求

`RG.Art` 提供 **11 种场景构图**（霓虹街区 / 像素回廊 / 深海 / 熔核 / 天穹 / 终章 / 静默 / 回声之海 / 共振塔 …）
与 **6 个角色剪影立绘**，全部用 Canvas 路径实时画出：

* **确定性**：同一个 seed 永远画出同一张画面（`RG.Art.background(kind, w, h, theme, seed)`）；
* **离线**：不发任何网络请求、不需要任何素材文件，`file://` 直接打开就有图；
* **用途**：游玩背景、大地图节点、待机画面与首页卡片；
* **缓存**：最多缓存 24 张画布，超出自动清空。

## 4.6 视角切换预告：沿轨道填满的白色区域

切换到另一个视角前 **5 秒**开始，一块**纯白半透明色块**会**沿着轨道从下往上逐渐填满**：

* 2D：从判定线往画面顶部铺满整块轨道区域（一个矩形色块）；
* 3D：贴着路面往远处铺 —— 路面在世界坐标里就是矩形，投影后仍是四边形，所以就是**一块贴合路面的白色四边形**，会跟着俯角/倾斜/震动一起变形；
* 到切换发生的那一帧**刚好填满**，随后 0.45 秒淡出，紧接着就是交叉溶解的视角过场；
* **没有描边、没有任何渐变、也没有推进边缘的亮线**：只有 `rgba(255,255,255,α)` 的纯色（α 最大 0.30，叠加模式 `lighter`，所以看着像"轨道被点亮"）；
* 淡出按时间计算（`now − 事件时刻`），掉帧也不会变慢或卡住；
* **不再显示任何数字倒计时**（HUD 上只剩「2D 平面视角 / 3D 立体视角」）。

## 4.7 3D 的连击数画在轨道上

3D 视角下，连击数不是平面 HUD，而是**贴在路面上**的一块字（`_drawComboOnRoad`）：

* 用路面投影的两条基向量（横向 + 纵深）构造画布变换，于是数字会随镜头**俯角、倾斜、震动、摇头**一起变形，真正和轨道在同一平面；
* **白色半透明**（`rgba(255,255,255,0.55)`）、**900 粗体**，字号是常规尺寸的 **4 倍**（≈2.16 个世界单位高）；
* 位置在判定线前方一点点的路面上（`z = 6.4`），视觉上略高于判定线，不挡读谱；
* 位数变多时按路面宽度自动收缩（4 位以上逐渐变小，始终不超出路面）；带 `COMBO` 字样与一层很淡的暗色投影保证可读性；
* 连击 < 2 时不显示；**切回 2D 时自动交还给平面 HUD**（`#gh-combo` 在 3D 下会加 `.on-road` 淡出，避免重复显示）；
* 设置页的实时预览里也照实呈现（连击数会随时间增长，自动交替模式下还能看到"沿轨道填满"的预告动效）。

## 5. 谱面格式

```jsonc
{
  "format": "rg-chart",
  "version": 1,
  "meta": {
    "id": "custom-abc123",       // 唯一 id
    "songId": "neon-drive",      // 内置曲目 id，或自定义
    "title": "我的谱面", "artist": "me",
    "difficulty": "自定义", "level": 9,
    "lanes": 4,                  // 1~10
    "bpm": 124, "offsetSec": 0,  // 音符时间=歌曲时间-offsetSec
    "length": 132,               // 秒
    "view": "2d",                // 起始视角：2d | 3d
    "viewEvents": [              // 内嵌的 2D/3D 切换环节
      { "t": 42.86, "mode": "3d", "dur": 1.0 },   // 到 42.86s 时用 1 秒过渡到 3D
      { "t": 68.57, "mode": "2d", "dur": 0.7 }
    ],
    "music": { /* 乐曲定义，见下 */ }
  },
  "notes": [
    { "t": 3.25, "lane": 0, "type": "tap" },
    { "t": 4.00, "lane": 1, "type": "hold",  "d": 1.5 },
    { "t": 6.00, "lane": 2, "type": "slide", "d": 0.75, "tail": 0 },
    { "t": 7.00, "lane": 3, "type": "flick" },
    { "t": 8.00, "lane": 0, "type": "mine" }
  ]
}
```

乐曲定义（`music`，程序化作曲参数——不含任何音频文件）：

```jsonc
{
  "style": "synthwave",   // synthwave | chiptune | pop | dnb | hardcore | ambient
  "seed": 1002,           // 同 seed 必然生成同一首曲子
  "bpm": 124, "rootMidi": 43, "scale": "minor",   // minor|major|dorian|penta|harmonic
  "sections": [ { "name": "intro", "intensity": 0, "bars": 8 }, { "name": "chorus", "intensity": 3, "bars": 16 } ]
}
```

## 8. 扩展

* **加曲目**：在 `src/songs.js` 的 `SONGS` 里加一条（曲风 + seed + 段落计划 + 三档难度等级与轨道数）即可，音乐与谱面都会自动生成。
* **加音符类型**：在 `chart.js` 的 `TYPES` 注册外观/基础分，在 `engine.js` 的 `onDown/onUp/update` 里补状态流转，在 `render.js` 的 `_drawNote2d/_drawNote3d` 补画法，编辑器会自动出现在工具栏。
* **换渲染器**：实现 `draw(frame)`、`laneAt(x,y)`、`judge(lane,result,delta)` 三个方法即可替换（3D 与 2D 就是同一接口的两套实现）。
* **加章节**：在 `CHAPTERS` 里加一条（位置、半径、布局方式、解锁星数），节点坐标会自动生成。
* **加场景画法**：在 `art.js` 的 `KINDS` 里加一个 `function(ctx,w,h,theme,rng)`，游玩背景按 `settings.background` 或直接传名字取用。
* **加教程步骤**：在 `tutorial.js` 的 `STEPS` 里插一条，给它 `play.notes`（音符数组）、`play.length` 与
  `play.require`（`noMiss` / `noBreak` / `clean`）即可；`art` 决定左边的示意图画法，`buildChart()` 会自动包成合法谱面。
* **加首页卡片**：在 `frontend.js` 的 `T.modes` 里加一条（`icon/name/sub/desc/chips/strip/actions`），
  手风琴会自动接管展开与收起；`strip.kind` 可以选 `stars/charts/ach/preview`，或自己加一种。
* **加成就**：在 `frontend.js` 的 `Achievements.list` 里加一条，并在 `Achievements.check()` 里补判定条件即可。
